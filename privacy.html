Política de Privacidad

Última actualización: 18 de septiembre de 2026.

Esta política describe cómo funciona actualmente El Camino Dental, un juego educativo de mesa digital desarrollado por Mtra. Yomira Salgado Martinez y publicado como proyecto web en GitHub Pages.

Resumen: el juego no requiere cuenta, no vende datos, no incluye publicidad ni analítica propia y no envía a un servidor propio los nombres de jugadores, respuestas o progreso de una partida.

1. Datos que utiliza el juego

El juego puede solicitar nombres o apodos de jugadores únicamente para identificar turnos dentro de la partida. También almacena localmente el avance de la partida, la posición de las fichas, personajes elegidos y elementos ya utilizados del banco de preguntas y casos clínicos.

Estos datos se guardan mediante localStorage en el navegador o dispositivo del usuario. No son enviados por el código del juego a una base de datos propia ni a un servidor administrado por la autora.

2. Datos que no solicitamos

  • No se requiere crear una cuenta ni iniciar sesión.
  • No se solicita nombre legal, domicilio, teléfono, correo electrónico ni fecha de nacimiento.
  • No se solicita información financiera.
  • No se solicita ubicación precisa.
  • No se solicita acceso a contactos, cámara, micrófono, galería o archivos personales.
  • No se integra publicidad ni seguimiento publicitario.
  • No se utiliza una herramienta propia de analítica de comportamiento.

3. Almacenamiento local y eliminación

El progreso permanece en el dispositivo hasta que el usuario reinicia la partida, borra los datos del sitio o elimina el almacenamiento de la aplicación. El usuario puede iniciar una nueva partida desde el propio juego para eliminar el progreso guardado de esa sesión.

Si el navegador o el sistema operativo elimina su almacenamiento local, el progreso también puede perderse.

4. Modo Docente y contenido creado por el usuario

El Modo Docente permite crear actividades, preguntas, casos clínicos, opciones de respuesta, respuestas correctas, instrucciones y retroalimentación. Ese contenido se guarda localmente en el dispositivo mediante localStorage. Si el docente activa una actividad para el tablero, las preguntas seleccionadas se leen desde ese mismo almacenamiento local. La función de exportar genera un archivo JSON en el propio dispositivo; la importación lee únicamente el archivo que el usuario selecciona.

El proyecto no envía automáticamente esas actividades a una base de datos propia ni las comparte con terceros. Se recomienda no introducir nombres completos de estudiantes, calificaciones institucionales, datos clínicos reales ni información sensible.

5. Alojamiento en GitHub Pages

La versión web está alojada en GitHub Pages. Aunque el juego no envía los datos de la partida a un servidor propio, GitHub puede procesar información técnica asociada a la visita al sitio, como dirección IP, información del dispositivo, fecha y hora de solicitudes y datos de uso del sitio, de acuerdo con sus propias prácticas de seguridad y privacidad.

GitHub indica además que las visitas a sitios de GitHub Pages generan registro de la dirección IP con fines de seguridad. Para conocer las prácticas de GitHub consulte su Declaración General de Privacidad.

6. Cookies y tecnologías similares

El código propio del juego no instala cookies publicitarias ni cookies de seguimiento. Utiliza almacenamiento local para mantener la partida. GitHub, como proveedor de alojamiento de la versión web, puede utilizar tecnologías necesarias para operar y proteger sus servicios conforme a su propia política.

7. Menores de edad

El juego tiene finalidad educativa y puede utilizarse en contextos académicos. No está diseñado para recopilar deliberadamente datos personales de niñas, niños o adolescentes. Se recomienda utilizar nombres de pila, apodos, números de equipo u otros identificadores no sensibles y evitar introducir información personal o clínica real.

8. Información clínica y educativa

Las preguntas y casos clínicos tienen finalidad docente. El sitio no solicita expedientes clínicos reales y no debe utilizarse para ingresar datos identificables de pacientes. El contenido del juego no sustituye la evaluación, diagnóstico o tratamiento profesional de un paciente real.

9. Terceros

El sitio puede contener enlaces a GitHub u otras fuentes de referencia. Al seguir un enlace externo, la política de privacidad aplicable será la del sitio de destino. Actualmente el juego no integra servicios externos de autenticación, publicidad, pagos ni analítica.

10. Seguridad

El proyecto intenta minimizar la recopilación de información mediante una arquitectura local y estática. Ningún sistema es totalmente inmune a riesgos. Se recomienda no introducir en el juego información sensible, contraseñas, datos de pacientes ni información que no sea necesaria para jugar.

11. Cambios futuros

Si una versión posterior incorpora servicios en línea, cuentas, sincronización, analítica, publicidad, almacenamiento remoto o permisos adicionales en Android, esta política deberá actualizarse antes de activar esas funciones.

12. Contacto

Para preguntas sobre privacidad, funcionamiento o contenido del proyecto puede utilizarse la sección pública de Issues del repositorio en GitHub.
